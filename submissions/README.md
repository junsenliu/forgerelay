## Shared release rules

- Public Apache-2.0 repository
- English-only submission and video
- Synthetic test data
- No mock behavior described as production
- No customer or supplier contact information in the repository or video
- Explicit disclosure of the July 26, 2026 creation date
- Explicit disclosure that the founder has pre-existing manufacturing
  experience and adjacent products, while this project and codebase are new
