# Build with DataHub — requirements checklist

- [ ] Project code created during the July 6–August 10 submission period
- [ ] DataHub Core running from the official quickstart
- [ ] DataHub MCP Server connected at runtime
- [ ] `search`, `get_entities`, and `get_lineage` visible in evidence
- [ ] Synthetic ForgeRelay assets and lineage seeded
- [ ] Agent retrieves ownership/lineage context before recommending action
- [ ] Optional result written back only after human confirmation
- [ ] Public repository with Apache-2.0 license
- [ ] Functional judge-accessible URL
- [ ] English demo video under three minutes
- [ ] Sample outputs in repository
- [ ] Pre-existing adjacent product ideas disclosed; no source code copied

## Judging story

Without DataHub, an RFQ agent sees only the pasted request. With DataHub, it
also sees which extracted constraint, call outcome, and quote package depend on
the changed fact, who owns the decision, and which downstream artifact must be
reviewed.
